# Estimoto + 0.1.0 (1) — first customer preview

This is the separate Estimoto + customer app, with its own E-plus app icon.

Try the Garage, PDR and Collision estimate drafts, Repairs, Find Help and Estibot tabs. Add a sample vehicle, explore a repair timeline, ask Estibot a car-care question, and review a technician request.

This beta intentionally uses fictional demo records. It does not contact a real shop, generate a production estimate, submit an insurance claim, or save information to your live Estimoto account. Demo edits reset when the app restarts. Live Estimoto integration, sign-in, push notifications and CARFAX are still being built.

Please use fictional information when trying the demo. Report issues to support@estimoto.io.
